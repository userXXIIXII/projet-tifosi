# Projet Tifosi

Base de données relationnelle pour la gestion d'une enseigne de focaccias.

## Fichiers du projet

* **import.sql** : Structure de la base de données (création des 8 tables et des contraintes)[cite: 2].
* **insert_data.sql** : Données de test et d'insertion (marques, boissons, ingrédients, focaccias, clients)[cite: 3].
* **backup_tifosi.sql** : Sauvegarde complète (structure + données)[cite: 1].

## Installation

1. Créez une base de données nommée `tifosi`.
2. Importez le fichier **import.sql** puis **insert_data.sql**.
*(Ou importez directement **backup_tifosi.sql**)*
